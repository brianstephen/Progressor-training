# Changelog

## v3.0
- Redesign: bottom tab bar with icons, header with connection dot and battery, hero cards for live and test readouts, force meter, consistent left (teal) and right (amber) colours, History as session cards, tidier chart axes, dark mode polish.

## v2.2
- Connect button hides while connected and returns on disconnect.

## v2.1
- Body weight and %BW, critical force test, 7 s hold, ±10% guide on the gap chart, Tindeq-format CSV export, peak smoothing, session notes.

## v2.0
- Blank tags default to `Low 22mm` everywhere, including imports and existing history.

## v1.9
- Optional automatic backup download on every save.

## v1.8
- Peak force tracks the selected hand continuously (no Start). Defaults to Right.

## v1.7
- Peak bar only on the Test tab.

## v1.6
- Always-visible Left/Right peak bar with a Save button. Nothing saved automatically. Delete sessions from History.

## v1.5
- Fixes: local timestamps, timestamp-reset handling, reconnect without the device picker, no duplicate listeners, quoted CSV fields, wake lock.

## v1.4
- Peak force test has no timer; Stop saves the peak.

## v1.3
- Live and Test separated. Peak test has no countdown.

## v1.2
- Bluetooth writes queued to avoid "GATT operation already in progress".

## v1.1
- Retry/restart logic that watches weight samples, Restart data button, packet counter.

## v1.0
- Version label added.

## Before v1.0
- Left/right peak recording, history with import of the Tindeq CSV export and duplicate handling, progress charts, personal bests, tags with filters, session pairing of left and right.
